# U2-ejercicio8

### Simulación de Batalla en Videojuego (Ataque y Daño)

Este ejercicio modela la interacción entre personajes de un videojuego RPG mediante la comunicación entre objetos en Java. Cada personaje posee un nombre, puntos de vida y poder de ataque. A través del método `atacar()`, un personaje envía un mensaje a su oponente para que ejecute `recibirDanio()`, modificando su salud. Además, se implementan validaciones para impedir que los personajes derrotados ataquen o reciban nuevos daños, simulando una batalla por turnos.
